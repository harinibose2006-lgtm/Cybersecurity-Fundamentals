# Cybersecurity Fundamentals Toolkit

## Project Description
A Python-based beginner-friendly toolkit
that explains important cybersecurity concepts.

## Features
- Introduction to Cybersecurity
- Types of Hackers
- CIA Triad
- Common Cyber Threats
- Cybersecurity Safety Tips

## Technology Used
- Python
- Visual Studio Code

## How to Run
1. Install Python.
2. Open the project folder.
3. Run the following command:

python cybersecurity.py
